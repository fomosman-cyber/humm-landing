# Skills

Herbruikbare skills voor dit account. `.claude/` staat in `.gitignore` (lokale
staat), dus de bron staat hier en wordt van hieruit geactiveerd.

## Activeren

```bash
mkdir -p .claude/skills
cp -r skills/moto-tiktok-cinematic .claude/skills/
```

In een nieuwe Claude Code-sessie in deze repo is de skill daarna beschikbaar.
Wil je hem overal hebben, kopieer dan naar `~/.claude/skills/` in plaats van
naar de repo.
